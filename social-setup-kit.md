## 4. Step-by-step setup

### A. Facebook Page (do this first)
1. Log into your personal Facebook account.
2. Go to **facebook.com/pages/create**.
3. **Page name:** Next Step Senior Consulting
4. **Category:** start typing "Senior Care Service" and select it.
5. **Bio:** paste the Facebook Intro copy from section 3. Click **Create Page**.
6. Upload **profile photo** (`mark.png`) and **cover photo** (`photo-hero-consult.webp`).
7. Open **Edit Page Info** → fill in phone, email, website, service area, and the long **About** text.
8. **Settings → Username** → set **@nextstepseniorconsulting** (this becomes facebook.com/nextstepseniorconsulting).
9. Add the **Call Now** action button near the top of the Page.

### B. Instagram (link it to the Page as you go)
1. Download the Instagram app (or use instagram.com) and **Sign up** with **info@next-step.place**.
2. **Username:** the same handle you used on Facebook.
3. Add **profile photo** (`mark.png`) and paste the **Instagram bio** + website link.
4. Go to **Settings → Account type and tools → Switch to Professional account** → choose **Business** → category **Senior Care Service**.
5. During that setup (or in **Edit profile → Page**), **connect your Facebook Page** — this links the two so you can post once and cross-share, and run things from one place later.
6. Turn on **Contact options** → add phone and email so the Call/Email buttons appear.

That Facebook↔Instagram link in step B5 is the key move — it lets you publish a post once and push it to both, and it's what you'll need later if you ever boost a post or run an ad.
